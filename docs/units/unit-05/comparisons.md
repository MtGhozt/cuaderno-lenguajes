# Unidad 5 — Comparaciones (scaffold)

## Comp 1 — Simula 67 vs Smalltalk

> **Fuente:** Guía Jorge S4C1 (banco de preguntas §4.2 Q1).

| | Simula 67 | Smalltalk |
|---|---|---|
| Pureza | OO + procedural Algol | Todo es objeto |
| Llamada | Invocación tipada / indirecta | Mensaje dinámico al receptor |
| Origen | Simulación eventos | GUI + pureza ontológica |

## Comp 2 — Herencia Java vs typeclasses Haskell

> **Fuente:** Guía Jorge S4C2 (banco §4.1 Q1).

- Java: polimorfismo por **subtipado y herencia** (`extends` / `implements`).
- Haskell: sin objetos; **typeclasses** como contratos; un tipo se adhiere sin modificar su definición.

## Comp 3 — OO vs imperativo (por qué «mató» a los imperativos clásicos)

> **Fuente:** Apuntes Jorge (ya en U2) + taxonomía Guía Jorge.

- Imperativo clásico no une estructura de datos + algoritmos de uso en una sola definición.
- OO encapsula estado + comportamiento detrás de una interfaz de mensajes.
